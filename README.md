# Help Desk Troubleshooting Labs

This portfolio documents hands-on troubleshooting
performed on my personal Windows laptop.

Each ticket includes the reported issue, investigation,
action taken, results, and verification.

## Environment
- Lenovo laptop
- Windows 11
- 4 GB RAM

## Tools Used
- Windows Task Manager
- Windows Settings
- File Explorer

## Tickets
- [Ticket 001: Slow Windows Performance](tickets/001-slow-performance.md)

## Skills Practiced
- Reviewing running processes
- Monitoring CPU, memory, and disk activity
- Testing potential causes
- Verifying system responsiveness
- Writing support documentation

## Scope
These are personal practice labs, not professional
customer support tickets.
